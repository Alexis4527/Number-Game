# Number-Game
This is a little number game, highest number gets a point.

If the ant’s number is higher than the game’s, the ant scores a point.
If the ladybug’s number is higher than the game’s, the ladybug scores a point.
If both the ant and ladybug have numbers higher than the game, both earn a point.
If the game’s number is higher than both the ant and ladybug, no points are given.

How to run this SwiftUI project

1. Clone or download the repository to your local machine:
2. Open the project in Xcode:
    Double-click the .xcodeproj or .xcworkspace file.
3. Build and run the project:
    Select an iOS Simulator (like iPhone 14) from the top bar.
     Press Cmd + R or click the ▶️ Run button.
